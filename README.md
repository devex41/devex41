## Проекты

### ⚡ Гибридный электропривод — опытный образец двигателя и контроллера
*~12 месяцев · Бакалаврская ВКР*

Разработка системы управления гибридной силовой установкой (параллельный гибрид, СДПМ в роли стартер-генератора) и изготовление опытного образца электродвигателя с нуля.

- Собственный векторный контроллер СДПМ: схемотехника, топология платы, прошивка на ESP32
- Опытный образец электродвигателя — спроектирован и изготовлен в металле
- Лазерный CO₂ ЧПУ-станок для резки электротехнической стали — разработан с нуля для нужд проекта
- Контроллер муфельной печи 10 кВт: импульсное регулирование, энкодер, 7-сегментный индикатор

`ESP32` `C++` `FreeRTOS` `IGBT` `Altium Designer` `векторное управление`

### 🌡 Измерительный прибор для калориметрических опытов
*~2 месяца*

Замена ртутного термометра Бекмана в лабораторном калориметре. Точность ~0,04 °C при диапазоне 20 °C.

- Аналоговый тракт: PT100, инструментальный усилитель на трёх ОУ
- Два интерфейса: цветной TFT-дисплей и веб-страница по Wi-Fi

`ESP32` `C++` `PT100` `аналоговая схемотехника` `EasyEDA`

---

### 🔭 Лазерный дальномер — реверс-инжиниринг и интеграция
*~2–3 месяца*

Превращение заводского фазового дальномера в автономный датчик без документации на электронику.

- Перехват данных через интерфейс дисплея ST7732: «прослушка» шины, декодирование кодировки вручную по hex-дампам с логического анализатора
- Эмуляция кнопок управления через оптроны

`ESP32` `C` `реверс-инжиниринг` `логический анализатор` `SPI`

### 🔌 Частотный преобразователь (скалярный → векторный)
*Итерационная разработка*

Разработка ЧП с нуля в двух итерациях.

- **Итерация 1 (скалярный U/f=const):** полностью рабочий. IGBT 600 В, драйверы FAN7382, изготовление платы методом фоторезиста
- **Итерация 2 (векторный):** ESP32, 3-фазный драйвер IR2233J, датчики тока ACS712. Плата готова, прошивка на этапе отладки

`ATmega328p` `ESP32` `C++` `IGBT` `EasyEDA` `Altium Designer`
